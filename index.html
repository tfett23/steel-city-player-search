Sleeper Full Player Search + Projections

Player search, ownership and Sleeper projections across both leagues.
Selected teams are an independent result set. Turn off “Include player pool” to compare only the selected teams.
Player Pool works like Yahoo: All Players, All Available, Free Agents Only, Waivers Only, or Owned Only. Include player pool and Include Team(s) are independent. Leave the pool on to compare selected teams against All Available/FA/Waivers/etc.; turn the pool off to compare only the selected teams. League and Match either/both are separate, so you can keep the cross-league searches. IR Eligible only uses each league's actual reserve eligibility settings and the player's current Sleeper designation. Free-agent vs waiver status is a best-effort reconstruction because Sleeper's public API does not expose a single authoritative player-pool-status field; this page combines roster ownership, pending waiver transactions, recent drops, current NFL game status, and the leagues' Tuesday lock behavior. Stats View changes the displayed stat line Yahoo-style. Stat-category columns adapt to the Position filter: offensive categories for offensive positions, IDP categories for defensive positions, and both when All Positions is selected. Rostered % uses Sleeper's undocumented research feed.
